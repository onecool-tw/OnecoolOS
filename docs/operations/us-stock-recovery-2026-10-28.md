# US research source recovery — 2026-10-28

The provider cache previously admitted undated quote-summary growth fields as
filing EPS comparisons. The recovery requires attributable source URLs and a
publication date, rejects unverified snapshots, and revalidates official inputs
for each completed US session. The existing score formulas and CTA engine are
unchanged. No technical ranking receives quality or valuation bonus points.

SEC requests use a bounded 12-second official JSON request path and three
concurrent workers. The checked-in CIK registry now covers the fixed candidate
universe and portfolio securities. Raw comparison pairs are retained. Verified
nonpositive comparison bases become rule exclusions without invented scores or
daily manual expiry extensions. Financial-company net revenue is supported on
the same tag/unit/period basis.

Reviewed official filing versions cover unavailable Company Facts fields,
explicit fourth-quarter EPS, ADR share/currency mappings, and split-restated
comparatives. Later eligible financial periods supersede older reviewed
versions. Earnings released after a cutoff cannot enter that cutoff's inputs.

The price fallback reads the same provider's daily chart with explicit adjusted
close factors. It adjusts the full OHLC consistently, rejects missing factors,
wrong securities/timezones, duplicate dates and mismatched calendars, and never
uses live quotes. It does not claim independent second-source agreement.

Background observations are rebuilt from the same run's validated histories.
Stale background prices are excluded rather than relabeled as current.
An old higher-coverage scan cannot conceal current mandatory provenance failure.

Valuation refresh retains the original sourced model assumptions and recalculates
the current cutoff's multiple. Reviewed source checks watch for new SEC filings;
failed disclosure checks cannot preserve a prior opinion. The new capital-
intensive research model includes a dated cash/debt/share-count and reported-FCF
cross-check, explicitly separate from owner earnings and full DCF valuation.
Unpublished transaction normalization remains a named external disclosure gap;
neither arithmetic nor an old balance sheet can fill it.

Validation: same-cutoff candidate, portfolio and background outputs were rebuilt
and checked before publication. Targeted tests cover missing provenance,
unverified snapshots, expired cache reuse, negative comparison bases, stale
background dates, chart adjustments and missing/duplicate observations. The full
suite's unrelated baseline failures were reproduced on the unchanged parent.
